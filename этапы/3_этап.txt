На данном этапе у меня в проекте:
В качестве основного хранилища сейчас PostgreSQL с ORM SQLAlchemy. in-memory Redis — она используется для кэширования анкет(чтобы не обращаться каждый раз к постгресу). Сервер принимает запросы от бота, валидирует входящие данные через схемы Pydantic и распределяет их по базам данных. Основное что было реализовано на данном 3 этапе — это эндпоинт поиска партнеров. Алгоритм берет город и хобби текущего пользователя, делает точную выборку совпадений из базы и формирует список кандидатов, автоматически исключая самого автора из этой выдачи. Бот управляет состояниями пользователя (FSM) и ведет его по шагам регистрации. Также я разработал асинхронный модуль для работы с медиафайлами (httpx + aiofiles). Бот перехватывает изображение из диалога ВК, асинхронно скачивает его на локальный диск сервера, а в базу данных записывает только уникальное имя файла. При просмотре карточек бот подтягивает фото обратно с сервера и отправляет в чат.

Как это выглядит со стороны юзера:
Он заходит в бота, заполняет анкету — указывает имя, город, свое хобби, загружает фотографию и немного рассказывает о себе. После этого он нажимает кнопку поиска, и бот сразу выдает ему карточки реальных людей из его города с точно таким же увлечением. Пользователь может легко листать анкеты кнопкой «Следующий» и, если кто-то понравился, прямо из бота в один клик перейти по ссылке и написать человеку в лс.
